# CampusHub

Aplicativo Android para alunos visualizarem eventos da universidade e se inscreverem neles.

## Funcionalidades

- Criação de conta e login.
- Recuperação de senha por e-mail.
- Edição do perfil do usuário.
- Listagem e detalhes dos eventos.
- Inscrição e cancelamento de inscrição.
- Tela **Meus eventos** com as inscrições do aluno.
- Sessão do usuário e opção de sair da conta.

## Tecnologias

- Kotlin.
- XML, AndroidX e Material Components.
- Firebase Authentication.
- Cloud Firestore.
- Gradle Kotlin DSL.

## Como executar

1. Abra o projeto no Android Studio.
2. Adicione o arquivo `google-services.json` dentro da pasta `app`.
3. Sincronize o projeto com o Gradle.
4. Execute em um emulador ou aparelho Android.

O pacote Android utilizado pelo projeto é `com.laurencekl.campushub`.
