# CampusHub

Aplicativo Android para alunos acompanharem eventos da universidade e se inscreverem neles.

## Stack

- Kotlin.
- XML, AndroidX e Material Components para as telas.
- Firebase Authentication para contas de usuários.
- Cloud Firestore para perfis, eventos e inscrições.
- Gradle Kotlin DSL.

Este primeiro commit contém apenas a estrutura inicial e as dependências, sem telas ou funcionalidades implementadas.
O projeto ainda não está conectado a um ambiente Firebase. O pacote Android é `com.laurencekl.campushub`.
